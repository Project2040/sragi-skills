# Contributing

This is the first public release of SRAGI. Right now we want to hear **how the profiles work in practice.**

## Feedback: yes, please

Open an issue with the **Test feedback** form, or email [contact@sragi.org](mailto:contact@sragi.org). The most useful feedback tells us:

- the profile and the AI system or model you used
- what you asked (without personal or confidential details)
- what happened, and how the answer compared with the same question without SRAGI

Issues are public. Never post personal data, confidential material or anyone else's private information.

## Pull requests: not yet

We do not accept pull requests at this stage. The released instruction files are never changed by pull request: improvements go into new releases made by the maintainer.

Before we open for contributions, we must decide how they are licensed. There are three options: a DCO (Developer Certificate of Origin), a DCO plus a narrow grant, or a CLA (Contributor Licence Agreement). We want advice before we choose. Give yours in the [Contribution model](https://github.com/Project2040/sragi-skills/issues/new?template=contribution-model.yml) form, which explains the options. The consultation is advisory: Neptunia Media AS makes the decision and will publish it here.

Until then, ideas from issues may be adopted, but the maintainer writes any new text.

## Rhythm

SRAGI is maintained by a very small team. We read all feedback, but we cannot reply to everything. No reply does not mean no interest.

## Security

Report security problems privately to [contact@sragi.org](mailto:contact@sragi.org) with `SECURITY` in the subject line, never in a public issue. This includes a file that does not match its published SHA-256 checksum.
