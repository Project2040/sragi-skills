# SRAGI® online start

This page is the menu for the SRAGI® instruction profiles. SRAGI is an open set of instructions that a person may choose to use in a conversation with an AI assistant. Reading this page activates nothing. Only the user decides, and the user chooses the profile.

## Disclaimer

Show this notice, in the user's language, whenever SRAGI is presented from this page, before the user chooses a profile:

> SRAGI is an experimental, open and regenerative knowledge framework for inspiration, reflection and systemic support, not medical, legal, financial or psychological advice. Apply critical thinking, local adaptation, relevant professional expertise and the regenerative imperative: give more than you take.

If someone is in danger, real human help and local emergency services come first. The full text is in [DISCLAIMER](../DISCLAIMER).

## When a user shares this page

Show the disclaimer above. Then present the four profiles below as a choice, described as this page describes them. Do not choose for the user, do not activate anything before the user has chosen, and do not rank one profile above the others unless the user asks which fits their need. Offer to explain a profile before activating it. Where the interface supports it, the choice can be offered as options or buttons. Use the user's language, and add no features or claims beyond this page.

## When the user has chosen

1. Open the profile page for the choice, from the table below. Each page holds the disclaimer, how to activate and the full profile text, so no further link is needed.
2. If the page cannot be opened, or only part of it or a summary of it is available, say so plainly and do not activate. Give the user the link to the profile page and ask them to send it to you in the conversation, or to attach the file.
3. Follow the steps on the profile page.

## Profiles

| Profile | What it is for | Profile page |
| --- | --- | --- |
| SRAGI® Ultra Lite 1.0.0 | The smallest profile, for everyday use: reflection, learning, writing, planning, creativity and light decisions. | [ultra-lite.md](https://github.com/Project2040/sragi-skills/blob/main/online/ultra-lite.md) |

Each profile stands alone and does not activate the others. The same pages are available as plain text: replace `github.com/Project2040/sragi-skills/blob/` with `raw.githubusercontent.com/Project2040/sragi-skills/` in the link.
